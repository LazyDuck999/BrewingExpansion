# 酿酒拓展 3.5 更新说明

酿酒拓展版本更新说明
v3.2.1 → v3.5
截至 2026-10-09 · 相对公开版 3.2.1 的改动汇总

01 流年酒柜：陈化与冰镇
过夜与涡轮：流年改为在过夜结算、使用涡轮加速器时完成机器效果。两种方式使用同一套陈化逻辑；涡轮完成后立即更新陈化天数、酒的价值与冰镇状态。
批量陈化：按本次机器周期应增加的天数直接结算，减少逐日重复计算。保留原版品质对陈化天数的影响，以及供电判断、每周期一次耗电和模块损耗。
连续过夜冰镇：修复已有冰镇标签的酒再次过夜后冰镇消失的问题。整晚处理完成后恢复应有的冰镇状态；酒正常继续陈化，冰镇仍需酒柜具备供电条件。
突破原版天数限制：流年使用64 位扩展陈化记录，支持超过原版陈化天数上限后继续累积；物品介绍显示完整天数。修复涡轮只加价值、不显示天数，以及超出上限后仍只显示原上限的问题。
旧陈化记录恢复：兼容之前已写入但未启用的扩展天数，连续涡轮和过夜保留累计记录；清除陈化时同步清零扩展天数，避免旧数据再次出现。

02 优化扩展：普通酒架与质量模块
普通酒架陈化：批量陈化优化扩展到原版普通酒架，保留原版可陈化条件、假酒跳过、供电判断与完成结算。普通酒架不会因此获得流年的冰镇能力；没有陈化功能的机器也不会新增陈化。
通用质量模块：优化扩展到使用原版机器完成结算入口的机器。对已核验的质量模块与简单效果合并重复统计，减少同一周期内反复计算属性的开销。
保留模块效果：各模块仍按原顺序执行使用动作和实际损耗，保留最终属性刷新。复杂效果、未知模块或其它模组改写了相关流程时，自动保留已有结算流程。
与其它优化模组同装：同装快速陈化过夜、ProbablyOptimized时，流年继续使用自己的批量陈化、扩展天数与冰镇逻辑；普通酒架和存在重叠挂钩的模块结算保留外部流程，避免重复接管。
性能说明：本次主要减少陈化与模块结算中的重复工作。实际耗时仍与酒瓶数量、模块数量及其它模组有关；不承诺所有机器或任意第三方模组都已适配。

03 旧存档兼容与分区修复
流年分区归位：加强3.0、3.2.1 与已保存的 3.3 错位酒柜兼容。读档时按物品类型和有效标签校正归属，并在读档完成后复查一次：电池在电池区、模组在模块区、酒在存放区。
模块错位修复：修复从 3.2.1 升级后模组再次落到电池区，以及拖入模块区后出现在屏幕下方的问题。目标分区不能接收时保留原物品，避免迁移过程中丢失内容。
新档与旧档贴图：完善开新档、读取存档和首次创建物品时的贴图准备，修复模组物品及酒瓶显示问号的相关问题，不再只依赖读档后的补载。
手办盲盒奖励：开箱前同步准备手办物品。修复双击后出现只有 ID 的问号奖励；读档时恢复已生成手办的名称、贴图和介绍。奖励创建异常时不把占位物品当奖品，也不消耗盲盒。

04 配方、交易与物品调整
种子事件估价：修复种子预估价值没有跟随市场事件变化的问题，兼容新生成种子、旧存档种子与已保存的商人库存。基础价值保持原值，预估价值随事件涨跌；例如基础价值 20 信用点，食物涨价 50% 时预估显示 30 信用点，事件结束后恢复 20 信用点。
酿酒配方价格：全部8 种配方残页基础价格统一为 50 信用点，旧存档中已有配方的基础价值同步刷新。
四十七配方上架：只从玩家尚未拥有的配方中选择上架，不再出售重复配方；玩家已拥有全部配方时，四十七不再携带配方。
未拥有配方提示：修复新档中尚未购买配方却能看到完整内容的问题。未拥有时显示锁定提示，取得对应配方后再显示正常内容。
收藏酒交易：普通烟酒类 NPC可以收购收藏酒盲盒中的酒，不再因物品分类不匹配而拒收。
酿酒商店折扣：修复酿酒商店继承博士友情价的问题。博士的15% 购买折扣只在博士商店生效，四十七的酿酒商店使用自身定价。
猫又又小挎包：外部占地调整为3×3，旧存档加载时同步修正；内部容量仍为8×8，价格不变。

05 特性贴图与人物界面
酿酒灯牌：替换为新制作的酿酒灯牌贴图，新生成灯牌与旧存档已有灯牌共用更新后的图标。
xuxu赞助：特性点消耗从 3.2.1 的2 点改为 1 点，开局赠送水质扫描仪与种子孵化器的效果不变。
五种专属特性图标：xuxu赞助、xuxu音乐、酩酊大醉、厌恶种子、一心为酒，全部替换为新制作的专属贴图。
新人酿酒师：开局职业选项左侧图标替换为新制作的新人酿酒师专属贴图，与五种特性图标一起更新。
四十七与泥泥：名字框与台词框调整为浅蓝色样式，保留原有边框和透明区域；旧存档中的访客在显示对话时同步更新。

06 新增独立模组：xuxu的MP3
独立 DLL：播放器拆分为XuxuMusic.dll · v1.0.0，以配套的酿酒拓展 3.5 为前置。需要播放器时，同时安装两份 DLL；公开版 3.2.1 不能直接作为这个播放器的前置。
免费桌面设施：进入店铺后，播放器直接出现在电脑右侧档案柜前的桌面，无需购买、不在酿酒商店上架、不能拖动。使用 mp3.png 专属贴图，占地3×2。
放入自己的音乐：将 MP3 文件直接放进游戏目录的Mods\xuxumusic文件夹。自动读取文件夹内全部 MP3，按文件名排序；不读取子文件夹，无需重新编译模组。
播放控制：单击桌面播放器打开面板，支持播放、暂停、上一首、下一首、停止、音量调节与刷新列表。音量范围 0%～100%，每次调整 10%；歌曲顺序循环播放。按钮文字统一居中。
悬停与介绍：显示游戏原生物品介绍框，修复“未拥有”提示。悬停范围仅有透明外边框，无绿色填充和内部格子。介绍署名为“来自xuxu”，加入“欢迎大家体验酿酒拓展、香烟拓展及更多外环区mod！”
歌曲与设置保存：当前歌曲文件名与音量随存档保存，读档后手动播放。旧 bemusic 目录在新目录不存在时自动改名；两个目录都存在时不覆盖歌曲。音乐文件仍保存在玩家电脑中。
与原版磁带共用声道：MP3 与原版磁带播放器共用音乐声道，启动原版磁带音乐时会停止当前 MP3。原有五盘磁带和磁带捆绑包的内容保留。
五盘磁带音量：提高酒吧特调、霓虹街道、微醺之夜、弦间微风、酿酒有嘻哈五首内置音乐的响度，缩小与原版磁带的音量差距。统一响度并限制峰值，保留适当动态余量；磁带物品 ID、文件名与播放时长保持兼容。
MP3 音量恢复：修复 MP3 停止或切回磁带后，共享音乐声道遗留 MP3 音量的问题。停止播放、原版磁带接管或音乐加载失败时，恢复游戏当前设置的音乐音量，避免影响后续磁带播放。

07 原版事件迁移与兼容修复
取消常驻帧更新：酿酒拓展与独立 MP3 均不再自行使用OnUpdate / OnLateUpdate。物品注册、窗口刷新、场景切换与机器工作改由游戏原版事件、物品使用回调及必要挂钩触发。
香水与盲盒使用：使用行为迁移到各物品的原版回调，修复迁移测试中香水无法使用、盲盒无法打开的问题；保留指定物品的可用性判断。
共享地址挂钩：移除物品形状共享原生地址上的挂钩，避免误拦截原版磁带播放器等对象。酒瓶打印机改为在创建及读档完成时恢复3×3占格。
窗口与场景清理：保留原窗口回调，避免重复绑定；修复离店、重置存档或场景销毁后，MP3 延迟任务继续访问旧界面的问题。开新档后重新安排桌面播放器生成。
